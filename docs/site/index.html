FastPaste

A clipboard history for Linux that is light and fast.

Press Ctrl+Alt+V, search, press Enter.

GitHub · Releases

X11 only for now. Tested on Linux Mint Cinnamon. Wayland does not allow a global shortcut or clipboard watching.

What it does

A background process records what you copy. The shortcut opens a popup on the mouse pointer; the pick is pasted into the app you were using. Written in Rust with Slint, software rendering only, no async runtime.

HistoryText, HTML and images, deduplicated, up to 500 entries.
SearchType to filter the history as you go.
ImagesPNG image copies with thumbnails in the list.
Shift+Enter optionsPaste as plain text, or trim, UPPER, lower and one-line transforms.
OCR (optional)Paste the text of a copied image, with tesseract installed.
Tray and autostartTray icon with Open, Preferences and Quit; start at login.
PrivateEverything stays on your machine. Copies from password managers are skipped; files are readable only by you.
TranslatedEnglish and Português (Brasil), following the system locale.

Install with Flatpak (updates itself)

This remote keeps FastPaste updated with flatpak update and your software centre:

flatpak remote-add --system --if-not-exists fastpaste https://evandro777.github.io/FastPaste/fastpaste.flatpakrepo
flatpak install --system fastpaste io.github.evandro777.FastPaste

Use --system: Linux Mint's Update Manager only looks at system-wide Flatpaks. The runtime comes from Flathub. The remote is GPG-signed, but the key lives in the source repository, so it is only as trustworthy as that.

For a desktop shortcut, bind a key to:

flatpak run io.github.evandro777.FastPaste --toggle
OCR in the Flatpak

The sandbox cannot see the host's tesseract. If you want OCR, install tesseract on the host and let the app run it there:

flatpak override --user --talk-name=org.freedesktop.Flatpak io.github.evandro777.FastPaste

This lets FastPaste start commands outside the sandbox, which removes most of what the sandbox protects. It is off by default; the AppImage has OCR without it.

Or the AppImage

Download FastPaste-<version>-x86_64.AppImage from the latest release, chmod +x it and run it. It uses the fontconfig, xkbcommon and X11 libraries already on your system, and carries update information, so AppImageUpdate, Gear Lever or AppManager download only what changed.

Run one of the two, not both: they use different data folders and fight over the shortcut.
